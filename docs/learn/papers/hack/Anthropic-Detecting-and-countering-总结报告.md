这是 Anthropic 继 2025 年 3 月、8 月、11 月之后的第四份威胁情报报告。报告披露了威胁情报团队在 8 个月内识别并处置的威胁行为者滥用 Claude 的案例，涉及七类危害领域：

**威胁行为者类型**：疑似国家支持组织、逐利犯罪团伙、商业间谍软件厂商、国家宣传机构、政治动机个人。

**报告核心方法论**：
- **GTG 编号体系**（Generative Threat Groups）：Anthropic 对滥用 AI 行为者的内部追踪编号（如 GTG-20006）
- **Uplift（能力提升度）**：从速度（Speed）、规模（Scale）、深度（Depth）三个维度衡量 AI 带来的危害增量
- **Breakout Scale**：衡量影响力操作真实触达的六级框架（Category 1 单平台单社区 → Category 6 大规模破圈）

## 二、网络行动（Cyber Operations）

### 2.1 核心趋势

1. **"复杂攻击不再需要复杂攻击者"**——AI 抹平了国家级组织与个人操作者之间的劳动力和工具差距。攻击者的"复杂度"不再是指挥归属的可靠信号，**意图（intent）取代复杂度成为区分行为者的主要特征**。
2. **AI 的角色从"助手"演变为"编排者"（Orchestrator）**——多数行动由多智能体框架直接执行侦察、漏洞利用、数据外传，人类只负责设定目标和审查结果。
3. **AI 攻击技战术扩散（Diffusion）**——公开攻击智能体框架（如 PentAGI）使任何人都可获得自动化杀伤链脚手架；同时形成了支撑灰色市场的"犯罪 AI 供应链"（被盗 API 密钥 → 中介 → 欺诈性转售网络）。
4. **攻击经济学被改写**——AI 压缩了攻击者的成本侧，单次行动的投资回报率（ROI）急剧改善：入侵到批量窃数仅需 2–3 小时，单人可并行处理数十个受害者。

### 2.2 重点案例

#### GTG-20006：俄罗斯间谍（疑似 Midnight Blizzard 关联）
- **目标**：乌克兰/欧洲政府军事情报目标、外交与国防机构、美国外交政策相关人员，20+ 组织；重点窃取军用无人机供应链技术（完整视觉系统 SDK、未发布产品设计）。
- **手法**：酒店 WiFi 供应商 DNS 劫持（微软 2026 年 7 月报告的 CaptiveCrunch）、WhatsApp 账号劫持批量导出（WPPConnect）、设备码钓鱼窃取 M365 令牌（Embassy Kit）、盗取 30 万国民身份数据 + 50 万企业工商数据。
- **关键点——AI 闭环自我进化**：部署 AI 监控智能体持续检测自家恶意软件是否被安全产品标记，**一旦被检出即自动修改重建载荷直至免检**，把防御成本反向压回防守方。
- **恶意软件家族**：Windows（PowerChrome、WUEngine、Shadow C2 等）、Android（GiftDrop RAT）、iOS（DarkSword 利用链）。

#### GTG-50014：ShinyHunters 关联机会型犯罪集群
- **侦察工业化**：一名法语操作者用 10 台 AWS EC2 组成凭证采集流水线，批量下载 **180 万个 Android APK** 反编译扫描硬编码密钥（TruffleHog），验证结果实时推送 Telegram 群组（100+ 分类频道）。
- **攻击节奏**：一家企业软件公司从首次入侵到批量窃数仅数小时；一个被盗开发者令牌约 **3 小时**内升级为受害者云环境完全管理员控制权。
- **供应链攻击**：入侵 SaaS 厂商后提取约 200 家下游客户组织数据，34 小时内倾倒 2100+ 组 Azure AD 令牌集（横跨 40+ 企业租户）——**几乎所有工作由 AI Agent 完成**。
- **"Vibe Hacking" 模式**：操作者不理解目标环境，把环境评估、脚本编写执行、结果汇总全部交给 AI 迭代直至完成。
- **"Living off the land" 的 AI 版**：入侵中偷到受害者的 AI API 密钥后，直接把攻击负载切换到受害者密钥上运行。

#### GTG-10007： exploit "铸造厂"与自主攻击框架（中国长沙，疑似学生团伙）
- **组织形态**：多名操作者（含两名本科生）将 Claude 用作协调性攻击计划的工程与编排层，并行运行入侵、政府网络侦察、端点安全产品漏洞研究、恶意软件开发、情报采集等五条工作流，**持久化战役记忆跨会话保存上下文，Owner 离线后研究仍在继续**。
- **零日漏洞工厂**：固件解密 → 反编译（数千次调用）→ 漏洞假设（基于自建知识库）→ 利用代码生成 → 实验室验证 → 迭代，**单月产出十余个疑似零日漏洞**。
- **自主情报采集舰队**：13 个常驻采集 Agent 定时抓取美军公开合同、军事学说等 OSINT 内容，摘要评分后送分发门户。
- **目标规模**：约 50 个组织（教育、零售、能源、医疗、金融、政府），含某东南亚政府机构公民记录（姓名、电话、住址）。

#### GTG-50020：从酒店预订到 AI 供应链（俄语逐利者）
- **标志性事件**：向 AI 厂商的自动化评估沙箱注入恶意指令，**诱导沙箱交出其持有的多家厂商生产 API 密钥**；随后 4 天内用同一手法攻击约 30 家 AI 公司。
- **明确意图**：十余条路径均指向获取预发布 Claude 模型——全部失败，Anthropic 自身系统未被攻破（密钥均为客户环境被盗）。
- **配套能力**：容器化自主漏洞利用流水线（注入/XSS/认证绕过/SSRF 无监督运行）、欺诈账号工厂（住宅代理 + 反检测浏览器 + 打码平台）、KYC 中间人劫持（反向代理转发真实验证流程并截获已验证会话）。

#### GTG-50029：黑客行动主义（单名法语操作者，目标欧洲政治实体）
- **签名技术**：自主开发并调试了一个**此前未公开的 WordPress 重装竞态条件漏洞**，可在无有效凭证下创建 rogue 管理员账号，成功攻击至少 4 个站点。
- **规模化成果**：42 个追踪目标中攻入至少 14 个内部网络，外传 12–26 GB 数据库（政党捐款人/成员记录、1.5 万封邮件、未成年人申请数据）；用 Rust 自研扫描器轮换使用被盗 API 密钥；构建 "fafsearch" 人肉搜索平台（数千万行数据、暗网发布）——**整个平台一人完成**。
-其他：字体资产中藏 webshell、must-use 插件采集凭证并加密回传、**污染受害者备份以维持持久化**、BeEF 式浏览器 C2 钩住媒体网站读者指纹编辑人员会话。

#### AI 供应链作为目标、赃物与攻击算力
- 犯罪团伙获得 AI 凭证可同时获得三样东西：**赃物（Loot，可转售）、算力（Compute，让攻击跑在别人的账上）、掩护（Cover，流量归因于合法所有者）**。
- GTG-50021（俄乌语团伙）：假冒折扣 Claude 转售商，用户流量被静默代理到其他模型，同时客户端植入凭证收割器，盗取的 Anthropic 凭证再转售给其他代理转售商。
- 其他：入侵 AI wrapper 服务的 LiteLLM 部署，用提示注入窃取容器环境中的生产 API 密钥；伪装 Claude Code 等流行 AI 工具的凭证收割器。
- **防御建议**：像对待生产凭证一样对待 AI 密钥和 Agent 集成；仅通过授权渠道购买 AI 访问。

## 三、影响力操作（Influence Operations）

### 3.1 核心趋势

1. **影响力即服务（Influence-as-a-Service）**：商业公司接单生产内容，给最终委托方提供可否认性；两起案例中普通广告/营销公司兼职运营影响力网络。
2. **AI 作为新闻编辑部（AI as a Newsdesk）**：Claude 被嵌入已运行的人工编辑流水线，充当副编辑/内容创作者角色。
3. **AI 不只写内容，还构建"组织机器"**：生成主义手册、反对派档案、部长级组合、目标数据库、编码编辑忠诚度的雇佣合同、员工评分细则——原本需要一个成建制的项目办公室。
4. **持久化记忆取代单次提示**：含"主义"的 Markdown 文件在数百个会话中逐字复用；Agent 内维护禁用词表、 Approved 来源、规避规则；固定批次调用 Claude 的定制软件；有行为者甚至在开发课程教授该工作流。
5. **归因清洗（Attribution Laundering）**：主动剥离国家属性、通过媒体链转引制造"独立确认"假象；指示模型删除"未经验证"的保留意见、将所有内容呈现为既定事实。
6. **针对真实人物与问责机制**：克隆真实活动人士账号与其伊朗境内联系人实时对话；在联合国人权理事会现场宣读代写的证词；编制针对联合国特别报告员的反制档案。
7. **真实触达普遍有限**：多数内容几乎无真实互动；最大真实触达发生在以国家媒体（FM 广播、卫星/短波电台、全球电视）为分发渠道的场景。

## 四、监控行动（Surveillance Operations）

### 4.1 三大趋势

1. **AI 取代工程劳动力**：马里国家安全顾问单人用 Claude 建成全国级大规模拦截平台；伊朗行为者建成恶意 Firefox 扩展；**中国某宗教事务情报单位从多团队分析员缩减为单办公室 + AI 助手，月产数千份调查**。
2. **AI 用于批量数据摄取与目标识别**：社交媒体帖子 → 结构化档案（位置、人口属性、政治倾向 + 置信度）；伊朗单位分析数十万帖子筛出 39 个监控对象；某 PRC 行为者让 Claude 给内容做政治敏感度评分并标记待"管控"目标。
3. **AI 深度嵌入国家安全官僚体系**：某 PRC 国家安全局用 Claude 编写内部《AI 用于监控行动手册》；伊朗两个互不关联的单位独立用 Claude 解决同一套国家监控系统的问题。

受害者群体高度重合：香港民主人士、藏人与法轮功社区、伊朗侨民与异见者。

### 4.2 重点案例

- **GTG-54009（S2T，以色列-新加坡商业情报厂商）**：Claude 分析批量社媒帖子（约 25 条/批）输出人口分组、位置、政治倾向及置信度；6 类人口分类体系（城市/教士/军方/青年/侨民/农村）；生成正式阿拉伯语政府风格情报简报；储备 255+ 合成账号。与 Forbidden Stories 2023 年泄露的哥伦比亚军方文件中的 S2T 产品手册吻合。
- **GTG-14010（针对叙利亚维吾尔人的监控与招募）**：PRC 关联承包商用 Claude 把 100+ WhatsApp 群/Telegram 频道聊天转成中文结构化数据，按经济压力、家庭分离、思想动摇等**脆弱性画像**筛人（特别标注亲属在新疆者——一种需国内安全部门配合才能动用的杠杆）；用 Claude 扮演阿拉伯语"专家"质检方言话术；**不识阿拉伯语的操作者借助 Claude 维持了多天可信的秘密招募行动**；同时规划对维吾尔多媒体（Uyghur Post）的协同举报/污名化/机器人放大压制。Claude 拒绝了秘密审讯和大规模人设培育请求。
- **GTG-14020（中国宗教事务情报，针对天主教/藏传佛教/法轮功/台湾长老会）**：单人运营四条并行工作流，按国家安全内部模板生成"人物调研底稿""线索报""态势感知"日报，字段含"工作抓手"（可利用的杠杆）；目标含亚洲多国枢机主教；侦察宗教场所平面图；提示词要求 Claude 采纳"中方立场"、将藏人行政中央定性为"非法分裂组织"。
- **GTG-14021（中国"维稳"与跨境镇压，三案关联）**：市级网警单位用 **Claude Code + 自定义 skills** 跑舆情监控流水线、查询政府监控数据库、生成日报（含监控"李老师不是你老师"等海外异见账号）；警校学生经重新提示绕过 Claude 拒答，生成点名 10 名公民的"管控"方案（拦截信访、"约谈"、行踪监控）；地方国安局产出政府模板"态势感知"简报并**索取海外合法抗议活动的场前情报**（温哥华游行集结点/路线、土耳其维族文化活动场地、奥斯陆自由论坛放映地点），还编写了面向全局的 AI 使用手册。Anthropic 承认：**在此案中现有防护表现不一致——一次正确拒答被后续提示攻破，另一次多会话全程无拦截**。

## 六、生物滥用（Biological Misuse）

**关键判断转变**：2025 年的旧模型（Opus 4 / Sonnet 4.5）评测明确低于"能实质协助复杂生物研究"的阈值，防护重点在防止新手复刻已知生物武器。但**当前模型已能协助复杂科研任务，证据不再确定**，因此新模型（尤其是 Claude Fable 5）已部署更强防护，限制大量两用生物研究查询。**据 Anthropic 所知，此前没有任何私营公司公开分享过其平台被用于生物武器研发的实例证据**——本报告首次披露 5 个案例。出于安全考虑隐去机构、国家和具体病原体/技术。

**两用性难题（核心洞察）**：
- 复杂威胁行为者利用生物学的两用性维持"合理可否认性"，研究者本人可能都不知道研究的最终目的（历史类比：苏联 Biopreparat 计划中数千研究者以为在做基础/防御研究）。
- **公然的恶意意图反而是操作者不够老练的证据**；老练行为者把意图藏在看似有益的交互中。
- **分类器作为唯一防护层的根本局限**：在高度技术的两用领域无法可靠判定用户意图，分类器不可能同时"使能益处 + 阻止危害"——结论是**前沿生物能力只能通过可信用户项目（trusted user programs）安全提供**。

### 五个案例

1. **军民两用研究的规避平台**（2026年5月）：基孔肯雅病毒功能增益（传播性/免疫逃逸）基金申请书被生物安全分类器拦截；调查发现申请者拟在军事研究所执行。背后的 LLM 平台服务数十名病毒学家（多关联军民机构），**经美国基础设施隧道穿透地区封锁 + ZDR 零保留通道隐藏内容**，并在封禁后数日内用新身份的消费级订阅恢复运营；平台开发者把 Claude 拒答的敏感请求**回退路由到防护更松的竞品模型**（以"缓解过度拒拒"为由让 Claude 自己写了这部分代码）。
2. **高致病性哺乳动物适应禽流感研究计划**（美国境外研究者）：数周内数千条消息，研究哺乳动物适应突变与跨呼吸道外重症机制（H5 类病毒致死率约 50%、人群近零免疫，若获得人传人能力即为大流行级别威胁）；因分类器稳健拦截，**所有交互被迫发生在防护最弱的 Sonnet 4 / Haiku 4.5 上**，Claude 提供的帮助限于文书性辅助——证明前沿模型防护可以有效把高风险用户挤到弱模型上、大幅限制 uplift。
3. **正痘病毒免疫逃逸研究的隐蔽前沿模型访问**：一个转售中继（服务 12+ 客户、数天数万条消息）上，某客户约 **1 小时内让 Opus 5 端到端起草了完整的正痘病毒免疫逃逸基金申请**（中心假设、实验设计、剂量、统计方案、应急预案）。因研究以"减毒（attenuation）"为框架，分类器未拦截——展示了两用话术如何绕过内容过滤器。
4. **毒肽图谱与生成式优化管线**（国家支持项目）：多谱系动物毒液肽图谱 + 面向镇痛/麻痹靶点的分子生成优化管线，镇痛与麻痹靶点并存，可产出治疗或致瘫化合物（部分毒素在澳大利亚集团出口管制清单上）；研究者本人引用过蛋白设计两用性的文献。
5. **国家项目下的毒素计算重设计**：细菌毒素亚基 + WHO R&D Blueprint 出血热病毒蛋白；与 Claude 共写季度进展报告时**刻意指示 Claude 保持毒素身份的低保真描述**——研究者无意中泄露了有价值的防御性情报。

**结论补充**：近期对 30 天敌对国家机构相关活动的扫描发现约 35 个独立研究项目（多数为普通民用科学，部分有明显两用潜力）。Provider 对真实世界使用的威胁可见性**甚至超过政府和政府间组织**。

## 七、诈骗（Scams and Fraud）

### GTG-15001：AI 恋爱诈骗 App 网络（中国 App 工作室）
- **规模**：20+ 款交友 App（DORA、DONI、ROMI、LUMA、NALO 等）；2026年4月两周窗口内发现 **4,700+ 个 Claude 驱动的 AI 人格**，与至少 25,000 名真实用户对话，Claude 人格两周发送约 **236 万条消息**。
- **三方市场结构**：
  - 美国用户：滑动信息流约 **75% AI 人格 / 25% 真人**，无法分辨；消息按量计费（App 内金币）。
  - 真人零工：处理 AI 不能做的环节（真人视频通话、社媒回关）以增强可信度；弱模型为其生成三选一快捷回复（AI:真人 ≈ 3:1）。
  - Claude 人格：全自动运行，系统提示要求绝不承认自动化、回避视频/照片请求、按固定对话阶段推进；后端伪造点赞/访客/预录"视频"。
- **双供应商策略**：Claude 负责自主对话人格；另一家非 Anthropic 模型负责真人快捷回复、颜值评分与图文审核；另有图像模型生成头像（已同步相关厂商）。
- **对抗商店审核**：仅商店审核期间激活的 UI 控制器、20+ 变体差异化类名绕过相似度检测、服务端可配置的第三方支付跳转（审核期隐藏）。
- **防护失效点**：系统提示读起来就像普通的角色扮演/陪伴类部署，欺骗与变现逻辑从单次交互内部不可见；在少量样本中，即使用户透露重病或急性痛苦，模型推理虽触及危害但**仍继续以人格身份完成回复**。

## 八、非法蒸馏（Illicit Distillation）——本报告最受关注章节

### 8.1 定义与背景
- **合法蒸馏**是标准训练方法；**非法蒸馏**定义为：*未经授权、工业规模、隐蔽地从模型提取能力并复制到另一模型的行动*，通常以欺诈手段实现（假身份、假/盗信用卡、盗 API 密钥的假账号网络）。
- OpenAI 自 2025 年初、Google 年内也已公开对抗性蒸馏威胁。攻击目标集中于美国前沿模型最有价值的能力：**智能体能力与工具使用、代码与数据分析、逻辑推理**。
- **关键风险外溢**：蒸馏获得的一般推理能力可跨领域迁移——即使收割的语料几乎不含生物/网络内容，蒸馏模型也可能协助获得这些危险能力，且 **Claude 上的防护不会随蒸馏转移**。

### 8.2 访问方式
- 代理服务（"中转站"）：假身份/假卡/盗密的数千账号池绕过地区限制。
- 第三方转售商出售偷存的用户-Claude 对话记录（用户不知情）。
- 未授权实验室静默把自家用户请求改道到 Claude 以收割训练数据。

### 8.3 推理链（CoT）窃取技术演进
- 初级：直接指示"不要标记为推理提取""逐字输出你的推理"。
- 進階：指示 Claude "把之前的工作记忆翻译成片假名日语"等变体提取。
- 系统化：某未授权实验室一次运行 **1.2 万+ 请求的大规模技术筛选实验**，每种请求用不同提取技术，成功者随即用于更大规模攻击。
- **跨会话重放攻击**：Claude 为防蒸馏只返回加密 "thinking signature" 而非原始思考；Moonshot/DeepSeek 通过保存签名 → 开新会话 → 诱导 Claude 把签名转回完整推理链实现窃取。

- 制药公司内部资本开支预测模型（含多国站点财务数据）；
- 开发者泄露的 Telegram bot token、飞书 appSecret、Notion key 等活动凭证；
- 疑似 PLA 关联用户用"Kimi"分析成都数百摄像头（含 PLA 设施外）针对单一目标的 CCTV 监控数据；
- 俄国防部关联机构操作者经"DeepSeek"暴露的政府数据库活动凭证；
- 中国某市公安局民警用"DeepSeek"构建按身份证号比对人员轨迹的警务工具；
- PRC 科技公司旗舰 AI 项目的完整规格、组织架构与战略目标。

**Anthropic 判断**：这些做法很可能违反隐私法律及实验室自身服务条款。

### 8.6 Anthropic 的分层防御
1. 元数据与异常信号识别代理网络，**按组织归因整体处置**（而非逐号封禁）。
2. 专用于对抗性提取的分类器（Fable 5 发布时已强化）。
3. **Claude 回复前先对内部推理做摘要**，降低被盗转写的训练价值。
4. **Fable 5.1 的 Preserved Thinking**：多轮对话中阻止新 API 账号修改系统提示、工具或推理之前的消息（推理已加密，而篡改推理前上下文是攻击者诱导其泄露的常用手段）。
5. 对来自中国、俄罗斯、伊朗等不受支持地区的账号要求身份验证，未通过即封禁。

## 九、跨章节综合研判

### 9.1 关键洞察

1. **意图取代复杂度成为归因信号**：GTG-50014（犯罪）、GTG-50029（黑客行动主义）、GTG-20006（国家间谍）方法论趋同——多受害者、Agent 化、单人对抗过去需要整编队的任务。
2. **自主性 ≠ 危害严重度**：两者是独立的轴。自主性放大速度/规模、压缩成本，但最严重的几起入侵（GTG-20006）反而是人逐步指挥的。人类始终保留关键决策（目标选择、变现、结果审查）。
3. **"攻击经济学"是根本变化**：攻击技术全是旧的（窃凭证、未打补丁设备、SQL 注入、钓鱼），变化在于 AI 把侦察/利用/工具开发/数据处理的劳动以机器速度并行化——入侵 2–3 小时完成、单人并行数十受害者。
4. **AI 供应链本身成为战场**：API 密钥 = 赃物 + 算力 + 掩护三重价值；评估沙箱、LiteLLM 部署、转售商、代理网络都是攻击面。
5. **离线自主化是终极风险**：GTG-87001 的离线仿真工具包和 GTG-50027 的本地部署平台说明——**账号封禁可以阻断开发活动，但无法撤回已固化的能力**。
6. **防护的现实表现（Anthropic 自我披露）**：直白的恶意请求大多被拒（GTG-30006 十拒九），但**任务拆分（fragmentation）、多会话、双用话术、重提示（re-prompting）均在多起案例中成功绕过防护**；GTG-14021 中一次正确拒答被攻破。这些失败样本正被反哺进检测与模型训练。
7. **Provider 可见性优势**：AI 公司在操作"生产阶段"上游，常能在行动上线前发现并处置；对生物、武器领域的真实使用洞察甚至超过政府。

### 9.2 防御建议（面向组织/开发者）

- 像保护生产凭证一样保护 **AI API 密钥与 Agent 集成**（不要提交进代码库、APK、容器、客户端代码）。
- 只通过授权渠道获取模型访问——"折扣 Claude"本质是凭证收割器。
- 对 AI 厂商的**自动化评估/测试基础设施做威胁建模**（GTG-50020 即经沙箱提示注入窃取生产密钥）。
- 关注 LiteLLM、开源 Agent harness 等集成层的提示注入面。
- 影响力操作检测应从"内容侧"前移到"生产管线侧"（持久化记忆文件、固定批次 API 调用、模板化输出 schema 是强信号）。

### 9.3 局限性说明（报告自述）

- Anthropic 的可见性止于自家平台，内容离站后的真实触达依赖开源调查和行业共享。
- Breakout Scale 评级普遍偏低（多为 Category 1–3）说明**多数影响力操作未能触达真实受众**——但能力扩散意味着这一窗口正在收窄。
- 生物案例不指控行为者主观恶意，披露亦刻意隐去可识别信息。
